Intercom in your Home Assistant dashboard

The widget runs in an authenticated Home Assistant custom panel or dashboard. Pass that host's hass object. A standalone HTML page cannot access another page's HA session or start a call.

Open Intercom Manager

Home Assistant custom cards

Add /intercom_m3_poc/cards.js?v=0.4.1 as a JavaScript module resource in Dashboard settings, then add a manual card:

type: custom:intercom-overview-card
title: Intercom rooms

# Or add call controls, optionally preselecting an enrolled UUID:
type: custom:intercom-room-card
device_id: YOUR_ENROLLED_DEVICE_UUID

HTML/JavaScript custom dashboard host

Inside your HA custom element, after HA supplies this.hass and your widget host exists:

import { mountIntercomWidget } from "/intercom_m3_poc/cards.js?v=0.4.1";
import { IntercomManagerClient } from "/intercom_m3_poc/client.js?v=0.4.1";

const mounted = mountIntercomWidget(hostElement, this.hass, {
  view: "call", // or "overview", "manager"
  device_id: "YOUR_ENROLLED_DEVICE_UUID"
});
// In your HA setter:
mounted.updateHass(newHass);
// On destruction/navigation, remove to stop media and release the mic:
mounted.remove();

const client = new IntercomManagerClient(this.hass);
const { rooms } = await client.snapshot();
// Administrator configuration edits include the revision automatically:
const config = await client.configuration();
if (config.rooms.length) {
  config.rooms[0].dnd = true;
  await client.update(config);
}
// An empty manager is valid. Use Rooms in Intercom Manager to configure it.

Do not put access tokens in HTML, URLs or browser storage. Use the HA host and the shared permission-checked controls. Browser calls require trusted HTTPS, a foreground page, microphone permission and an explicit CALL gesture. Removing the widget, hiding the page or losing its control connection ends media.

Removal: delete custom cards and the cards.js dashboard resource; remove the integration entry to disable its sidebar and API. No iframe or cross-origin authentication shortcut is provided.
